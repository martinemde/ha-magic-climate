# Magic Climate

Generic Home Assistant custom integration that wraps any `climate.*` entity to add:

- **UI-configured presets** — define `away`, `home`, `eco`, `sleep`, etc. from the HA UI; no YAML, no device reflashing.
- **Dual-setpoint UI fix** — auto-detected; produces the correct number of temperature sliders per HVAC mode for climate entities that support `HEAT_COOL` with dual setpoints.

Status: under construction.
